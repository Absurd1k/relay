# Relay

Лёгкое portable-приложение для Windows 10/11 x64: Telegram MTProto → WebSocket, Discord, YouTube и отдельный маршрут к AI-сервисам в одном интерфейсе.

**Rust + Win32/GDI. Без Python, Electron, WebView и установки компонентов.**

## Запуск

1. Поместите `Relay.exe` в обычную папку с правом записи и откройте его.
2. Для Discord / YouTube и AI используйте «Перезапустить с правами» или запуск от имени администратора.
3. Выберите сервисы и нажмите «Подключить». Движки можно запускать раздельно.
4. Для Telegram нажмите «Подключить в Telegram» и подтвердите локальный прокси в клиенте.
5. Если Discord / YouTube недоступны, остановите движки, выберите другую стратегию в настройках и повторите проверку.
6. Для ChatGPT / Claude / Gemini откройте «Нейросети», прочитайте название провайдера и нажмите «Включить AI-маршрут». Перезапустите браузер. Кнопка на главной странице сама этот внешний маршрут не включает.

В первой версии нет универсального автоматического подбора стратегии. Работоспособность зависит от провайдера и сети. HTTPS-диагностика не подтверждает видео и голосовые звонки; проверьте их в приложениях. Telegram Web проверяется отдельно от локального MTProto-прокси.

## Один exe

Telegram-движок скомпилирован в тот же exe как Rust-библиотека. При подключении Telegram Relay запускает собственный exe с внутренним параметром `--tg-worker` как скрытый фоновый процесс. Интерпретаторы не используются.

Архив zapret, стратегии, библиотеки и лицензии встроены в файл. При первом открытии они автоматически распаковываются в `Relay_data/engines` рядом с exe: драйвер и DLL Windows должны загружаться из отдельных файлов. Пользователю достаточно одного `Relay.exe`, ничего скачивать не нужно. Для переноса настроек скопируйте также `Relay_data/config.json`.

Крестик и кнопка сворачивания скрывают Relay в системный трей возле часов. Подключения продолжают работать. Нажатие на значок возвращает окно; правый клик открывает меню «Открыть Relay» / «Выход». Положение значка в основном трее или под стрелкой скрытых значков определяет Windows.

Полный выход — через «Выход» в меню значка или «Полностью выйти» в разделе «О приложении». Тогда движки завершаются и AI hosts-блок удаляется. Windows Job Object с `KILL_ON_JOB_CLOSE` завершит Telegram-процесс и при аварии оболочки. **После полного выхода отключите локальный прокси в Telegram**, иначе клиент будет пытаться подключиться к остановленному серверу. При перезапуске Проводника приложение повторно регистрирует значок; если значок создать не удалось, окно остаётся доступным.

Автозапуск включается по желанию в настройках. Discord / YouTube запускается через собственную службу Windows `RelayZapret`. AI-режим по отдельной кнопке добавляет управляемый блок в системный hosts. Telegram и zapret этот файл не меняют. Аккаунт Telegram, коды входа и доступ к сообщениям приложению не нужны.

## Новое в 0.2.0

Зимнее оформление: северное сияние, 180 снежинок размером 3–6 px, светящаяся переливающаяся гирлянда и ёлка. Анимация рисуется средствами Win32/GDI с частотой до 12,5 кадров/с; при скрытии окна и потере фокуса таймер выключается. Её можно отключить кнопкой в заголовке. Поле порта оформлено в тёмной теме, включая недоступное состояние.

В списке стратегий доступны только ALT 1–13. `service.bat` управляет upstream-службой и не является стратегией; BAT-файлы Relay не исполняет. Старые базовые профили при загрузке настроек заменяются на ALT 1 с сохранением Telegram-секрета.

Служба `RelayZapret` создаётся при первом включении Discord / YouTube с правами администратора. Движок и списки копируются в защищённую папку `%ProgramFiles%/RelayPortableZapret/<версия архива>`. Служба работает от LocalSystem, имеет ручной запуск и останавливается при полном выходе из Relay; в трее продолжает работать. После аварии оболочки служба может остаться запущенной, следующий запуск Relay с правами администратора подключится к ней. Если уже работает отдельная служба Flowseal `zapret`, Relay сообщает о конфликте и не изменяет её.

В разделе «Обновления» можно включить автоматическую проверку GitHub каждые 30 минут. Опубликованные релизы и prerelease с более новой SemVer-версией и файлом `Relay.exe` скачиваются автоматически; файл проверяется по размеру, SHA-256 из GitHub и заголовку Windows x64. Кнопка установки перезапускает приложение с сохранёнными подключениями. При ошибке запуска установщик пытается вернуть предыдущий exe. Проверка обновлений передаёт GitHub обычный HTTP-запрос без настроек и Telegram-секрета. В версии 0.1.0 обновлятора нет — на 0.2.0 нужно перейти вручную один раз.

## Автозапуск и сохранение настроек

1. Включите нужные сервисы и выберите стратегию / порт. Эти настройки сохраняются автоматически, включая секрет Telegram и состояния сервисов.
2. В «Настройках» включите «Запускать при входе в Windows». Для настройки нужно один раз открыть Relay с правами администратора.
3. При этом включается «Восстанавливать включённые сервисы». После входа в Windows Relay автоматически запускает сохранённые Telegram / zapret / AI. Секрет Telegram сохраняется, поэтому добавлять прокси заново не требуется.

Автозапуск создаёт одно задание `RelayPortable-<SID текущего пользователя>` в Планировщике Windows, с интерактивным входом того же пользователя и уровнем Highest. Пароли и учётная запись SYSTEM не используются. Время выполнения не ограничено, работа от батареи разрешена. Это позволяет zapret и AI запускаться с нужными правами без нового UAC-запроса при каждом входе. Для обычного ручного запуска автоподключения Windows может запросить повышение прав.

Отключить автозапуск можно тем же переключателем; удаляется только задание Relay для текущего пользователя. После перемещения portable exe выключите и включите опцию заново, чтобы обновить путь. При автозапуске окно сразу скрыто в трее. Автоподключение можно отключить отдельно, сохранив фоновый запуск приложения.

Состояния изменяются при явном включении/отключении сервисов. Крестик скрывает окно и сохраняет работающие подключения. Полный выход останавливает процессы и восстанавливает hosts, сохраняя профиль для следующего запуска. Кнопка «Отключить всё» сбрасывает состояния подключения. Новая версия не включает автозапуск или восстановление автоматически для старого конфига.

## Память

- Нативный Win32/GDI интерфейс, без OpenGL-контекста.
- Однопоточный Tokio runtime для Telegram; ограничение 64 клиентских подключений, пул 2, буферы 16 KiB.
- Журнал ограничен 300 событиями; длина строк и очередь тоже ограничены.
- Контроль процессов раз в 500 мс, измерение памяти раз в 5 секунд.
- Сетевые проверки только по кнопке.

Показатель RAM — сумма working set оболочки и запущенных ею процессов. Общие страницы могут учитываться повторно. Во время разработки оболочка показала около 13 МБ working set в простое; это замер на одном ПК без активной передачи трафика, а не гарантия для всех систем. Подробности — в [протоколе проверок](docs/VALIDATION.md).

## Telegram на Rust

Используется существующий MIT-порт [valnesfjord/tg-ws-proxy-rs](https://github.com/valnesfjord/tg-ws-proxy-rs), закреплённый на коммите `53f392280a370199ffe5c6ef0ac88808ed17c575` (2.7.0). Это интеграция стороннего порта подхода Flowseal, а не заявление, что весь протокол заново написан автором Relay.

Код библиотеки не изменён. В Relay добавлены запуск в worker-режиме, ограничение ресурсов и контроль жизненного цикла. Список fallback-доменов берётся из самой библиотеки, поэтому запуск не требует загрузки списка с GitHub. Проверка TLS сохраняется; небезопасный режим отключения проверки сертификатов не включается.

## Нейросети

Реализован маршрут через публичный SNI-прокси [dns.malw.link](https://github.com/ImMALWARE/dns.malw.link). Встроен отфильтрованный список из 43 AI-доменов (снимок от 14 ноября 2026, коммит `062b1a8687e6c2606c0bd4b06e833e65cfaefb29`). Он не включает правила блокировки рекламы, игр и других сервисов из списка провайдера. Обновление адресов — через новый выпуск exe.

Если ограничение основано на стране IP, локальный DPI-обход её не меняет: нужен внешний сервер. Этот маршрут использует стороннего оператора. Сертификаты и TLS не подменяются. Работа сайта, вход, генерация ответов и ограничения аккаунта — разные проверки; доступ не гарантируется.

Перед изменением сохраняется бэкап `Relay_data/hosts-backup-*.txt`. При отключении AI и полном выходе удаляется только блок Relay; чужие записи и более поздние правки вне блока сохраняются. В трее AI-маршрут остаётся активным. Если AI-домен уже прописан в hosts вручную, включение прерывается. Повреждённые маркеры не удаляются автоматически. При невозможности восстановления полный выход прерывается с ошибкой и окно показывается; при принудительном завершении или отключении питания блок может остаться. Следующий запуск с правами администратора восстанавливает его. Исследование альтернатив и границы проверок: [docs/AI_ACCESS.md](docs/AI_ACCESS.md).

## Происхождение компонентов

- [Flowseal/zapret-discord-youtube 1.10.3](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.3).
- [bol-van/zapret](https://github.com/bol-van/zapret).
- [basil00/WinDivert](https://github.com/basil00/WinDivert).
- [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) — исходный подход Telegram-прокси.

Relay — независимый проект и не является официальным продуктом этих авторов или владельцев сервисов. Лицензии включены в архив и доступны после распаковки.

Встроенный архив и файлы проверяются по SHA-256. Это контроль целостности, а не цифровая подпись exe. Обновления компонентов поставляются внутри нового exe; начиная с 0.2.0 приложение умеет скачивать новые релизы с GitHub.

BAT-файлы **не исполняются**: парсер извлекает только список аргументов `winws.exe`. Команды `service.bat`, `CALL` и `START` не выполняются. GameFilter выключен (upstream порт-заглушка `12`). Изменяемых списков доменов в GUI пока нет.

Секрет MTProto сохраняется в `Relay_data/config.json`, скрывается в журнале и присутствует в ссылке подключения. Не публикуйте файл конфигурации или свою ссылку.

## Сборка

Для разработчика: Rust stable, Visual Studio C++ Build Tools и Windows SDK. Python не нужен ни для сборки, ни для запуска.

```powershell
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo build --release --locked
```

Готовый файл — `target/release/relay.exe`. `Cargo.lock` фиксирует зависимости, включая коммит Telegram-библиотеки. Артефакты zapret уже лежат в `assets/engines.zip`. Для их пересборки: `./scripts/build-engines.ps1`.

`Relay.exe --verify-bundle` проверяет встроенный архив без запуска GUI и сетевых движков.
