# Relay v0.2.1

Предварительный выпуск для Windows 10/11 x64. Скачайте `Relay.exe` и поместите рядом с прежней папкой `Relay_data`, чтобы сохранить настройки и секрет Telegram. Перед заменой закройте старое приложение через «Полностью выйти».

- Зимний фон: северное сияние, снег, светящаяся гирлянда и ёлка. Ползунки плотности снега и плавности 15–60 кадров/с, сохранение настроек, остановка анимации в трее и без фокуса.
- Исправлены углы кнопок, тёмное поле порта и фон ползунков.
- В списке стратегий только ALT 1–13. Discord / YouTube запускается собственной службой Windows RelayZapret; работающий отдельный zapret не изменяется.
- Подбор ALT одной кнопкой с прямыми HTTPS-проверками, отменой и попыткой восстановления прежнего подключения при неудаче.
- Диагностика служб, процессов, возможных VPN/туннелей и локального порта Telegram.
- Быстрое управление подключениями и профилями из меню трея.
- Автоматическая проверка обновлений только при запуске, ручная — по кнопке. Новые exe скачиваются и проверяются по SHA-256 и PE x64.
- Исправлена наблюдавшаяся ошибка обновления HTTP 403: вместо лимитированного REST API используются публичная Atom-лента GitHub и SHA256SUMS.txt. Токен GitHub приложению не нужен.

**Для 0.1.0 и 0.2.0:** если встроенное обновление отсутствует или показывает 403, перейдите на 0.2.1 вручную один раз. Автозапуск ссылается на полный путь exe: при его перемещении выключите и включите автозапуск заново.

Проверены clippy, release-сборка, 31 обычный тест и отдельный сетевой тест с настоящим скачиванием релиза и сверкой SHA-256 без запуска скачанного файла. GUI-установка будущего обновления и полный перебор ALT в реальной заблокированной сети не подтверждены. HTTPS-проверки не гарантируют видео YouTube и голос Discord. VPN-диагностика даёт признаки возможного конфликта, а не доказательство.

Архив `third-party-sources.zip` содержит соответствующие исходники сторонних Cygwin / WinDivert. Все файлы проверяются по `SHA256SUMS.txt`. Приложение не подписано сертификатом издателя; SHA-256 — контроль целостности.
