# Relay v0.1.0

Первый публичный предварительный выпуск для **Windows 10/11 x64**.

Скачайте **Relay.exe** и поместите в папку с правом записи. Установка и отдельные зависимости не нужны.

В этой версии:

- Нативный интерфейс на Rust / Win32, без Python, Electron и WebView.
- Telegram MTProto → WebSocket на основе Rust-порта valnesfjord/tg-ws-proxy-rs.
- Discord / YouTube через встроенные стратегии Flowseal zapret 1.10.3.
- Отдельный AI-маршрут через публичного оператора dns.malw.link.
- Крестик скрывает окно в системный трей; полный выход — через меню значка.
- Сохранение настроек и состояний сервисов, опциональное автоподключение.
- Автозапуск через Планировщик Windows с повышенными правами; старт сразу в трее.
- SHA-256 встроенных компонентов, ограниченный журнал и измерение памяти.

Для zapret, AI и настройки автозапуска нужны права администратора. Сначала включите нужные сервисы, затем настройте восстановление в разделе «Настройки».

## Проверки и ограничения

20 тестов Relay проходят, release-сборка и clippy выполнены. Сквозная MTProto-проверка Telegram получила ответ через WebSocket. Работа из конкретной российской сети, видео YouTube и голос Discord не подтверждены. В upstream Rust-порте есть отмеченные в протоколе неуспешные сетевые тесты.

ChatGPT и Gemini ответили HTTP 200 через выбранный публичный AI-прокси; Claude показал Cloudflare challenge. Это не подтверждает вход в аккаунт, генерацию или доступность из любой страны. Публичный оператор может менять адреса и доступность. AI выключен по умолчанию и при включении меняет только управляемый блок hosts; при полном выходе блок удаляется.

Сборка не подписана сертификатом разработчика. Включены исходники и лицензии сторонних компонентов. Relay — независимый проект и не является официальным продуктом Flowseal, Telegram, Discord, YouTube или AI-сервисов.

Артефакты: `Relay.exe`, `Relay-source.zip`, `third-party-sources.zip`, `SHA256SUMS.txt`. Пакет сторонних исходников не нужен для обычного запуска.
